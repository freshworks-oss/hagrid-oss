# Version [3.3.0] - [16th April 2024]

## Fixed
### Removing Instance of AnalyticsService from AnalyticsFactory
AnalyticsFactory has a `singleton hashMap`, which maintains the single instance of `analyticsService` against namespace as a key. 
Earlier, when sync is done, we were not removing entry for the `namespace` from `singletonHashMap` which might cause memory leak. 
In this version, in `SyncService` when a method `clearSync` is called, within that, we fetch do something like 

```java


    public void clearSync() throws InterruptedException {

        this.infraService.destroy();
        this.syncServiceContainer.clear();
        AnalyticsFactory analyticsFactory = getAnalyticsFactory();
        String namespace = this.namespace.getNamespace();
        analyticsFactory.sigterm(namespace);  -->Here it is
    }

```
