# Version [3.5.0] - [COMPLETED]

## Added
### Support for Multipackage of Step, Bean & Assets

Today in Hagrid, developers need to provide the path where steps , beans  and assets  exists.
This path  is mentioned in hagrid.yml  like below

```java

configuration:
connector:
step_path: "com.freshworks.core.data.fb.steps"
bean_path: "com.freshworks.core.data.fb.beans"
asset_path: "com.freshworks.core.data.fb.assets"
```


Hagrid scans for steps, beans and assets in these packages, not in any of its inner packages.
There have been the use cases, where developer want to organise the steps in more better way like having multiple packages under step_path .

So instead of specifying all inner packages, expectations is that when Hagrid scans for the step_path  then it should scan all its inner packages as well.

Similarly idea goes for bean_path  and asset_path .

I am going ahead with solution number where in providing the top level package in enough for developer. Hagrid will scan all its inner packages.

DSR for this feature is [Multi-package-step-beans-asset-support](https://github.com/freshdesk/hagrid/issues/297)
